# v11.1 自由描述与问答返回契约修复

本版保留 v11 会话格式及模型，旧记录可继续。主要修改 dialogue.py、intent_system_v3.txt、server.py 和版本显示。

- 用户输入按完整问题/回答发送，不设问题例子的词汇白名单。鸭腿等具体词可作为对象线索，但不直接等于讨食意图成立。
- 逐轮输出示例改为本次每个真实候选 ID 的完整槽位，并明确 expected_intent_ids；不再只示范一个占位候选。
- 兼容 candidates / intents / active_candidates 对应 assessments、brief_reason 对应 reason、primary_intent_id 对应 selected_intent_id，以及支持/矛盾引用的等价结构。同名别名冲突、未知 ID、虚构引用仍拒绝。
- 漏候选时返回应有 ID 和实际 ID，要求一次有上限的格式修正；不自动补造支持或排除，不强行接受不完整结论。
- 提问要求结合历史，例子不是封闭选项；已回答事项不换个说法反复问，未知对象允许开放式追问。
- 继续会话记录实际使用的新提示词版本 3.1。旧模型与密钥、数据库不变。

验证：92 项 Python 测试通过；包含本次 6 项新自由文本/字段适配/漏项修复测试。测试使用模拟 LLM 返回，没有真实调用 DeepSeek；无法仅凭截图确定你上次返回究竟漏了哪个字段。来源与状态校验仍不证明语义正确。

更新：关闭旧窗口，解压完整包，将新 PawTalk_Web_Clean 文件夹里面的内容复制到原 PawTalk_Web_Clean 里面，替换同名程序文件；不删除原文件夹。运行原目录 00_START_APP.bat，显示 v11.1。原有录音记录可从探索记录继续，无需重训/重装模型。
