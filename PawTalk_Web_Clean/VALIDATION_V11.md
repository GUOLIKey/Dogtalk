## 用户本机最小验收

1. 关闭旧窗口，用更新器合并代码；00 标题及网页显示 v11。
2. 上传已能正常处理的录音。查看完整 8+3+3 分数及新的派生摘要；按你之前 usable=false 的结果，应显示 F-UNCERTAIN，不应硬套 E1–E4。
3. 生成候选，确认初始 possible。若不足三个，看到原因；若零个，可继续问背景。
4. 回答不知道，不应凭此排除；回答真实观察，再更正，查看修订记录。
5. 结束后重新生成，检查八问剩余预算没有恢复为 8。导出应带 rules_version=v0.2 和 schema_version=intent-session-v3。

只反馈界面错误、模型状态和无密钥的日志；不需要发送 API Key。
