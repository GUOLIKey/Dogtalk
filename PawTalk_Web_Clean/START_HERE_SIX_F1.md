# 看新的场景模型 F1：按这个顺序操作

## 1. 关闭旧网页的黑色运行窗口

暂时不用打开网页，不用填 DeepSeek 密钥。此次只跑场景模型，情绪模型不参与训练。

## 2. 解压修改包，覆盖程序文件

解压后看到 `PawTalk_Web_Clean` 文件夹。

打开它，按 Ctrl+A 全选**里面的文件和文件夹**，复制到你电脑上原来的：

`D:\PawTalk_Barkopedia_数据核查与模型准备包\PawTalk_Web_Clean\`

出现同名提示时选“替换目标中的文件”。**不是把整个新文件夹再拖进原文件夹里。**

原来的 data、models、state、DEEPSEEK_CONFIG.ini 都保留，不要删除。可以先复制一份旧 PawTalk_Web_Clean 做备份。包里没有你的密钥、模型权重或原始数据。

正确放置后，应直接看到：

`D:\PawTalk_Barkopedia_数据核查与模型准备包\PawTalk_Web_Clean\09_TRAIN_SIX_AND_SHOW_F1.bat`

不应该是 `...\PawTalk_Web_Clean\PawTalk_Web_Clean\09_...bat`。

## 3. 双击 09_TRAIN_SIX_AND_SHOW_F1.bat

程序会自动：

1. 使用原项目 `.venv`，检查音频和原锁定留出清单。
2. 优先复用已导出的特征或原 CLAP/MFCC 缓存，避免重复提取。无原缓存导出条件时，从实际 DEV 录音提取。
3. 在相同数据和划分下分别训练八类与六类，检查重复/分组；有跨折问题时两者一起修正划分。
4. 计算 OOF Macro-F1、Accuracy、逐类表现、混淆矩阵和逐折结果；训练完成后安装新六类权重/缓存，自动打开本地结果网页。

这是**训练与交叉验证**，不是上传一段录音，可能明显更久。CLAP 有 CUDA 时可用 GPU，sklearn SVM 本身使用 CPU；没有针对你电脑实测，不承诺几分钟完成。显示 `[CV] fold=...` 后可能数分钟没有新一行，不要重复双击。窗口需一直开着。

如果出现 STOPPED 或 FAILED，先不要继续运行 00。发送错误截图或 `results\scene_six_v1\train_日期时间.log`。不要发密钥。原缓存校验不一致时会停止，不会悄悄换特征。`11_TRAIN_FROM_AUDIO.bat` 是明确从音频重新提取的备用入口，首次请先运行 09；不要因为校验失败就直接绕过原因。

## 4. 看报告第三行

报告主表按时长 ≥ 1 秒的 DEV OOF 子集统计，通常4,954条：

| 行 | 含义 | 你应该怎么看 |
|---|---|---|
| 原八分类模型 | 原八类任务 | 背景成绩 |
| 原八类预测映射六类 | 六类基线 | 比较基准 |
| **重新训练六分类模型** | **真正的新模型** | **看这一行的 Macro-F1** |

用第三行与第二行比较，才是在相同六类任务上检验重训是否有帮助。不要把 F1 叫作 Accuracy，也不要把类别合并后的数字说成原八类任务提升。

如果没有打开网页，双击 **10_VIEW_SCENE_RESULTS.bat**。没有成功训练时，10只显示旧历史映射结果，并明确写“真正六分类重训尚未完成”。

每次真实训练结果在 `results\scene_six_v1\trained_run_日期时间\`。`summary.txt` 是便于发给我的摘要；`report.html` 是网页报告；`metrics.json`、`comparison.csv` 和各类 confusion/per_class CSV 是完整结果。

**请把这次训练目录里的 summary.txt 发给我**，我就能分析真正六分类的 F1；如果需要逐类诊断，再加 metrics.json。

## 5. 训练成功后，才运行 00_START_APP.bat

页面/终端显示 `PawTalk Web Six Scenes v1`。本次训练不需要情绪或 LLM；完整 App 双路流程仍需要你原来可用的情绪运行配置和 DeepSeek 配置。训练结果不能证明最终意图准确率。
